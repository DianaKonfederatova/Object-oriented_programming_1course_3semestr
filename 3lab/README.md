# Лабораторная №3

## Класс Matrix
**Назначение:** хранение и безопасная работа с двумерными матрицами целых чисел произвольной размерности в динамической памяти.

### Основные возможности
1. **Создание матриц** тремя способами: пустой (`0×0`), единичной квадратной (`size×size`) и заполненной нулями (`rows×cols`).
2. **Безопасный доступ к элементам:** чтение (`get`) и изменение (`set`) значений ячеек по индексам с проверкой выхода за границы матрицы.
3. **Заполнение данными:** ввод элементов вручную с клавиатуры (`inputFromKeyboard`) и генерация случайных чисел от `0` до `99` (`fillRandom`).
4. **Вывод в терминал:** построчное отображение элементов матрицы на экран (`print`).
5. **Получение характеристик:** подсчёт суммы всех элементов (`sum`), а также получение количества строк (`getRows`) и столбцов (`getCols`).

### Особенности реализации
* **Инкапсуляция:** все поля класса (`data_`, `rows_`, `cols_`) скрыты в секции `private`, доступ к ним возможен только через публичные методы.
* **Ручное управление памятью:** память под двумерный массив выделяется построчно в конструкторах (`new[]`) и освобождается в обратном порядке в деструкторе (`delete[]`).
* **Пустая матрица:** при передаче нулевой размерности (`0×0` и т. п.) память не выделяется (`data_ == nullptr`), что безопасно обрабатывается деструктором и всеми методами класса.
* **Обработка ошибок и защита типов:** используется `explicit` для конструктора с одним параметром, а при некорректных входных данных выбрасываются исключения `std::invalid_argument` и `std::out_of_range`.


## Компиляция и запуск

Сборка проекта предупреждениями компилятора:
```bash
g++ -std=c++17 -Wall -Wextra main.cpp Matrix.cpp -o lab3
```

Запуск демонстрационной программы:
```bash
./lab3
```

## Ожидаемые результаты программы
Программа поочерёдно создаёт несколько матриц с помощью разных конструкторов и выводит их на экран. Затем она перезаписывает их содержимое разными способами: по формуле, случайными числами и значениями с клавиатуры. После этого программа подсчитывает сумму элементов матрицы и использует её размеры (количество строк и столбцов). В конце намеренно передаются некорректные данные при создании матрицы и обращении к её элементам, чтобы проверить перехват исключений (программа должна вывести сообщения об ошибках и корректно продолжить работу).
