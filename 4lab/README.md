# Лабораторная №4

## Класс Matrix
**Назначение:** хранение и безопасная работа с двумерными матрицами целых чисел произвольной размерности в динамической памяти с реализацией «Правила трёх».

### Основные возможности
1. **Создание матриц** тремя способами: пустой (`0×0`), единичной квадратной (`size×size`) и заполненной нулями (`rows×cols`).
2. **Глубокое копирование при создании:** конструктор копирования (`Matrix(const Matrix& other)`) создаёт полную независимую копию существующей матрицы с выделением новой памяти.
3. **Копирующее присваивание:** перегруженный оператор `operator=` корректно освобождает старую память целевого объекта, копирует новые данные и поддерживает цепочки присваиваний (`d = e = a`).
4. **Безопасный доступ и обработка:** чтение (`get`) и изменение (`set`) элементов с проверкой границ, заполнение (`fillRandom`, `inputFromKeyboard`), подсчёт суммы (`sum`), получение размеров (`getRows`, `getCols`) и вывод на экран (`print`).

### Особенности реализации
* **Правило трёх:** в классе явно определены деструктор, конструктор копирования и оператор копирующего присваивания для безопасного владения ресурсами в куче.
* **Защита от самоприсваивания:** в `operator=` реализована проверка `if (this == &other) return *this;`, предотвращающая удаление собственных данных при присваивании объекта самому себе (`a = a`).
* **Пустая матрица:** оба новых метода корректно обрабатывают матрицы нулевой размерности (`0×0`), не выделяя память и оставляя `data_ == nullptr`.
* **Инкапсуляция и исключения:** поля класса (`data_`, `rows_`, `cols_`) скрыты в секции `private`, а при некорректных размерах или индексах выбрасываются `std::invalid_argument` и `std::out_of_range`.

### Почему деструктор не вызывается дважды для одной и той же памяти
1. **Независимое выделение памяти:** конструктор копирования и `operator=` не копируют адрес указателя `data_`, а выделяют новый блок памяти через `new[]` и поэлементно переносят значения. Каждый объект владеет собственной областью памяти.
2. **Очистка и обнуление в `operator=`:** перед выделением новой памяти старые строки и массив указателей удаляются через `delete[]`, а `data_` приравнивается к `nullptr`. Это исключает висячие указатели (особенно при присваивании пустой матрицы `0×0`).
3. **Проверка на самоприсваивание:** проверка `if (this == &other)` гарантирует, что при выполнении `a = a` память объекта не будет преждевременно освобождена.

## Компиляция и запуск

Сборка проекта без предупреждений компилятора:
```bash
g++ -std=c++17 -Wall -Wextra main.cpp Matrix.cpp -o lab4
```

Запуск демонстрационной программы:
```bash
./lab4
```

## Ожидаемые результаты программы
Программа создаёт исходную матрицу `a` размером `3×4` со случайными числами и создаёт её копию `b` через конструктор копирования. После изменения элемента в `b` программа выводит обе матрицы, подтверждая, что `a` осталась неизменной. Затем проверяется оператор присваивания на матрице другого размера (`c = a`), цепочка присваиваний для пустых матриц (`d = e = a`) и самоприсваивание (`a = a`).
